# Handoff Info: A Primeira Estante Viva

## Handoff Summary

Construir um experimento mínimo para um pequeno grupo de leitores. Cada pessoa oferece uma foto de uma estante, um print do Kindle ou um conjunto inicial de livros. O sistema reconhece os títulos, cria uma estante virtual visitável e usa a imagem física como capa ou miniatura quando disponível. A experiência ganha vida por movimentos simples: começar a ler um livro e registrar insights durante a leitura. Esses movimentos são enviados a um grupo compartilhado no Telegram, onde as conversas já podem acontecer. O objetivo é descobrir se estantes visíveis e sinais de leitura geram curiosidade, visitas, perguntas e circulação entre pessoas.

## Attractors

- **A Estante** (`proposed`)
  - A geografia autoral dos livros na vida de alguém. Pode compreender vários móveis, superfícies e lugares da casa, cada qual com um significado próprio. A estante virtual reúne essa constelação sem apagar onde e como cada grupo reside.

## Experiment Status

**A Primeira Estante Viva** (`proposed`)

Criar uma experiência mínima para o grupo inicial. Cada pessoa envia uma foto de uma estante ou conjunto de livros. O sistema reconhece os títulos visíveis, usa a foto como capa e miniatura do perfil e oferece uma estante visitável. A vida inicial da experiência vem de dois movimentos: marcar que começou a ler um livro e registrar um insight surgido durante a leitura. Ambos podem enviar uma mensagem para o grupo compartilhado no Telegram, com autoria, livro, conteúdo do movimento e caminho para visitar a estante. O início de leitura oferece contexto, enquanto os insights criam uma cadência mais frequente e dão matéria concreta para conversa. Não incluir ainda feed próprio, resenhas completas, mensagens internas, timeline elaborada ou regras amplas de rede. O experimento observa se as pessoas registram insights com naturalidade, se essas mensagens despertam conversa e se a frequência produz vida sem se tornar ruído.
