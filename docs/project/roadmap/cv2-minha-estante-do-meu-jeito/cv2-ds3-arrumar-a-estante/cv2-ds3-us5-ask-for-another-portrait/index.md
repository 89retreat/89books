# CV2.DS3.US5 — Ask for another portrait

**Status:** Planned · conditional

## Candidate User Story

Como pessoa que já corrigiu e arrumou a própria estante, quero poder pedir
outro retrato a partir dos livros que ficaram para receber uma nova proposta de
abertura e prateleiras sem reler as fotos.

## Candidate Outcome

- `portrait` guarda a fonte atual antes de reescrever.
- O custo estimado em centavos é mostrado e exige confirmação explícita.
- A operação usa os livros atuais e não relê fotos nem reconhecimento.
- A nova proposta substitui abertura e prateleiras somente porque a pessoa a
  pediu; `draw` continua gratuito.

## Pull Condition

Não faz parte do escopo necessário para fechar CV2.DS3. Puxar somente se uso
real mostrar que fundadores querem uma nova proposta da IA depois de editar à
mão. Ausência desse pedido é evidência para mantê-la planejada, não uma lacuna
técnica.
