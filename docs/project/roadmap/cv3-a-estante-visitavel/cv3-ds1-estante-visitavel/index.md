# CV3.DS1 — Estante visitável

**Status:** Planned

---

## Outcome

A estante chega a quem a pessoa quiser, como arquivo, como link ou das duas
formas, e quem a recebe consegue visitá-la no celular.

## Candidate Stories

| Code | Story | Type | Outcome | Status |
|------|-------|------|---------|--------|
| CV3.DS1.US1 | Publicar minha estante no GitHub Pages | User Story | Com um comando, escolho publicar a estante num endereço difícil de adivinhar e recebo o link para mandar a quem quiser; sem esse comando, nada sai da minha máquina além das chamadas ao modelo e aos catálogos. Publica o que o `shelf.yaml` diz, sem os livros escondidos. | Planned |
| CV3.DS1.US2 | Ver as estantes do grupo num só lugar | User Story | Uma página lista as estantes publicadas do grupo pela capa de cada uma e leva a qualquer uma delas. Depende da decisão sobre onde publicar. | Planned |

## Done Condition

As estantes do grupo foram vistas por outras pessoas, por arquivo ou por link,
e a decisão sobre onde publicar está registrada.
