# Interface principal da CV1

## Question

A entrada e os movimentos acontecem num web app pensado para celular, ou o bot
do Telegram é a interface principal (recebe foto, comandos e insights), com a
estante visitável como página web?

Importa porque define a stack, o esforço da DS2 e da DS4 e o quanto o grupo
precisa instalar ou aprender.

## Decision

Pending

## Rationale

O bot reduz o atrito (o grupo já está no Telegram) e já é o canal dos
movimentos. O web app dá mais controle sobre a revisão do reconhecimento e a
estética da estante.

## Options Considered

- Web app pensado para celular, com bot só para enviar mensagens ao grupo.
- Bot como interface principal, com páginas web só para ver estantes.
- Híbrido: entrada e revisão no web app, movimentos pelo bot.
