# Onde as estantes são publicadas no GitHub Pages

## Question

Quando a pessoa escolhe publicar a estante, ela vai para um repositório da
org 89retreat, comum a todos, ou para um repositório pessoal de cada um?

## Decision

Pending

## Rationale

O repositório da org junta as estantes num só endereço e permite uma página
com as estantes do grupo (CV3.DS1.US2). O repositório pessoal deixa cada um
dono das próprias fotos, inclusive para apagá-las, e não mistura permissões.

Atenção: no plano gratuito, o GitHub Pages publica a partir de repositórios
públicos; num repositório privado da org exige plano pago. Confirmar antes de
decidir.

## Options Considered

- Repositório da org 89retreat, uma pasta por pessoa.
- Repositório pessoal de cada um.
