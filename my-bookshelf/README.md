# my-bookshelf

Put the photos of your bookshelf here, then run `uv run shelf` from the root
of the repository. See [GETTING_STARTED.md](../GETTING_STARTED.md).

- One shelf per photo, taken straight on, in good light, reads best.
- `.jpg`, `.heic` (iPhone), `.png` and `.webp` all work.

Everything in this folder stays on your machine: git ignores it all except
this file. That includes your photos, `config.toml` (which holds your keys),
the generated `shelf.html` and `books.yaml`, and the `.shelf/` cache.
