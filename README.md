# 89books

Um produto para leitores ávidos, nascido da frustração de um grupo de amigos
com o Goodreads. O ponto de partida é a estante: visitar a estante de alguém
é uma forma de encontrá-lo.

A [CV1 A Primeira Estante Viva](docs/project/roadmap/cv1-primeira-estante-viva/index.md)
provou que cada fundador consegue transformar fotos numa página com os seus
livros e um retrato de si como leitor. A
[CV2 Minha estante, do meu jeito](docs/project/roadmap/cv2-minha-estante-do-meu-jeito/index.md)
transforma essa primeira leitura numa estante que a pessoa pode ajustar sem
pagar de novo.

## Create once, draw for free

**New here? Follow [GETTING_STARTED.md](GETTING_STARTED.md)**: from clone to
an editable shelf and its page.

Put photos in `my-bookshelf/` (`.jpg`, `.heic`, `.png` or `.webp), then run:

```bash
uv run shelf create   # paid: reads the photos and creates shelf.yaml once
uv run shelf draw     # free: draws shelf.html from shelf.yaml
uv run shelf open     # free: opens the page
```

The first `create` asks for your name and keys, checks them, shows the
estimated cost and waits for confirmation. It never replaces an existing
`shelf.yaml`. `draw` needs no API key and makes no network call; it saves a
changed source in `history/` before replacing the page. If the file is invalid,
it reports the lines and preserves the previous page. The command
without a verb shows photos, books, edit/draw times, version count, current
state and the next safe verb; `check` lists every YAML problem.

A folder generated by the CV1 command already has `books.yaml`. `create`
reuses those books, covers and provenance without recognizing photos or
calling catalogues again. It pays only for a new portrait and leaves the
legacy files untouched.

Other commands and options:

```bash
uv run shelf                         # status and next safe action; never spends
uv run shelf check                   # validate shelf.yaml with line numbers
uv run shelf history                 # list saved versions without reading them
uv run shelf restore VERSION         # save the current source, then restore one
uv run shelf recreate                # paid: save the source, then rebuild from photos
uv run shelf setup                   # change name or keys
uv run shelf draw --folder other/    # use another folder
uv run shelf create --yes            # explicit consent in scripts or automation
```

Without `--folder`, the current directory is used when it already contains a
shelf or shelf photos; otherwise the command falls back to `my-bookshelf/`.
An explicit `--folder` always wins.

The shelf folder contains:

- `shelf.yaml`: the versioned, human-editable source — name, cover photo,
  portrait opening, ordered shelves and ordered books. This is what survives
  every free redraw.
- `shelf.html`: a self-contained page with the photo mosaic, reader portrait,
  covers and drawn spines. File previews such as Quick Look do not run its
  layout; open it in Chrome or Safari.
- `config.toml`: your name and API keys, kept local and ignored by git.
- `.shelf/`: local catalogue, cover caches and the last-drawn content marker.
- `history/`: at most 20 exact `shelf.yaml` versions, kept local and ignored by git.
- `books.yaml`, when present: the CV1 output used only for the first migration.
  It is no longer the source after `shelf.yaml` exists.

Photos are resized and stripped of metadata (EXIF) before they are sent to the
model or embedded in the page. The HTML never contains your API key or local
paths. OpenRouter calls only providers configured not to keep data for
training.

Run `uv run shelf --help` for the command list.

`CLAUDE.md` aponta para ele). As regras locais estão no
